# MVP Scope

## In scope

- Meeting management
- Multiple offerings per meeting
- Donor management
- Gift Aid declarations
- Donation recording
- Named donations
- Anonymous donations
- Loose cash
- Cash denomination recording
- Cheques
- Tithe / general / special donation types
- Attendance
- Two-person signing (counter + checker)
- Guest signing
- Locked offerings (immutable after signing)
- Amendments (append-only, never destructive)
- Audit trail
- Banking
- Banking reconciliation
- Gift Aid reporting
- GASDS calculation / reporting
- Bookkeeping report
- Donor donation report
- GDPR subject-access report
- RBAC (role-based access control)
- Local authentication
- SQLite storage
- Offline operation
- Automatic local backup
- Manual backup / restore
- Seven-year retention (visible, no auto-deletion)
- Access-data migration where possible

## Out of scope (post-MVP)

- Bank-transfer donations
- HMRC API submission
- QuickBooks / IIF export
- PostgreSQL deployment
- S3 / cloud backup
- Postcode lookup
- Donor self-service
- Electronic Gift Aid declarations
- Email reports
